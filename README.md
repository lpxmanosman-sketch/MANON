## 🛍️ صفحات وأقسام المتجر للعملاء (Storefront)

1. **الصفحة الرئيسية (`index.php`):**
   - قسم البطل (Hero Section) مع الشعار الرسمي، عبارة *"عبايتك فخامة تليق بك"*، وزر *"تسوقي الآن"*.
   - قسم التصنيفات (Categories Showcase).
   - قسم مختارات منون المميزة (Featured Products).
   - بنر العروض والخصومات مع زر استشارة تفصيل واتساب.
   - قسم أحدث العبايات وصولاً (New Arrivals).
   - قسم "لماذا تختارين منون؟" (أقمشة كورية ويابانية، حياكة يدوية، تغليف ملكي).
   - تقييمات عميلات منون الحقيقية.
   - معرض إنستغرام التفاعلي والفوتر الفاخر.

2. **متجر العبايات (`shop.php`):**
   - عرض شبكي أنيق للمنتجات مع تصفية حسب التصنيف، نطاق السعر، والترتيب (الأحدث، السعر، الأكثر شعبية).
   - البحث الحي بالاسم والكود والخامة.

3. **تفاصيل العباية (`product.php`):**
   - معرض صور المنتج مع ميزة التبديل السلس بين الصور المصغرة.
   - تفاصيل الخامة واللون وحالة التوفر.
   - محدد المقاسات (52، 54، 56، 58، 60) مع نافذة منبثقة لجدول المقاسات.
   - زر إضافة للسلة بـ AJAX.
   - زر مباشر لطلب نفس العباية عبر الواتساب.
   - قسم عبايات ذات صلة وإرشادات العناية والغسيل.

4. **سلة المشتريات (`cart.php`):**
   - استعراض المنتجات المضافة، المقاس، السعر، والكمية.
   - أزرار زيادة ونقصان الكمية ديناميكياً وحذف المنتجات أو إفراغ السلة.
   - ملخص الطلب والزر المباشر لإتمام الشراء.

5. **إتمام الطلب ونظام الواتساب (`checkout.php` & `order-success.php`):**
   - نموذج سهل وسريع لبيانات العميلة (الاسم، الهاتف، واتساب، المحافظة، العنوان، ملاحظات).
   - زر بارز: **"إرسال الطلب عبر واتساب"**.
   - تسجيل الطلب تلقائياً في قاعدة البيانات برقم فريد (مثل `MANON-260922-123`).
   - توليد وتشفير رسالة الواتساب بالصيغة المطلوبة وتوجيه العميلة مباشرة إلى:
     `https://wa.me/201273572887?text=...`

6. **عن منون (`about.php`):**
   - قصة العلامة التجارية، فلسفة التصميم، والاهتمام بأدق تفاصيل الخياطة والأقمشة.

7. **تواصل معنا (`contact.php`):**
   - قنوات التواصل المباشر، الهاتف، البريد، العنوان، ونموذج إرسال رسالة وقسم الأسئلة الشائعة (FAQ).

## ⚙️ لوحة التحكم للمدير (Admin Panel `/admin`)

1. **تسجيل الدخول الآمن (`admin/login.php`):**
   - تشفير كلمات المرور باستخدام خوارزمية `password_hash()` الآمنة.
   - حماية الجلسة ضد هجمات تثبيت الجلسة وحماية CSRF.
2. **الرئيسية والإحصائيات (`admin/dashboard.php`):**
   - إجمالي المبيعات، إجمالي الطلبات، عدد المنتجات، وعدد التصنيفات.
   - جدول أحدث الطلبات الواردة مع حالاتها وإجراءات سريعة.
   - قائمة العبايات الأكثر مشاهدة في المتجر.
3. **إدارة المنتجات (`admin/products.php`):**
   - استعراض المنتجات وتصفيتها والبحث فيها.
   - إضافة عباية جديدة (`admin/product-add.php`) مع رفع آمن للصورة الرئيسية ومعرض صور إضافي.
   - تعديل العباية (`admin/product-edit.php`) مع إمكانية حذف وإضافة صور للمعرض وتحديث المخزون.
   - حذف المنتج بأمان.
4. **إدارة التصنيفات (`admin/categories.php`):**
   - إضافة تصنيف جديد، تعديله، وحذفه مع فحص أمان وجود منتجات مرتبطة.
5. **إدارة الطلبات (`admin/orders.php`):**
   - تصنيف الطلبات حسب الحالة (جديد، مؤكد، قيد التجهيز، تم التوصيل، ملغي).
   - تغيير سريع لحالة الطلب من الجدول.
   - صفحة التفاصيل الكاملة للطلب (`admin/order-details.php`) مع زر مباشر **"مراسلة العميلة عبر واتساب"**.
6. **سجل العميلات (`admin/customers.php`):**
   - قائمة العميلات، أرقام هواتفهن، إجمالي مبالغ مشترياتهن، وتاريخ آخر طلب مع زر محادثة واتساب مباشر.
7. **إعدادات المتجر (`admin/settings.php`):**
   - تعديل اسم المتجر، الشعار، رقم الواتساب الرسمي، الهاتف، العملة، شريط الإعلانات، وتغيير كلمة مرور المدير.

## 🔒 معايير الأمان المطبقة (Security Standards)

- **منع SQL Injection:** استخدام **PDO** حصرًا مع استعلامات معدة مسبقًا (Prepared Statements).
- **منع XSS:** حماية كافة المخرجات باستخدام دالة `htmlspecialchars()` عبر الدالة المساعدة `e()`.
- **حماية CSRF:** توليد وتدقيق رموز الجلسة السرية (CSRF Tokens) في كل نموذج إرسال.
- **تشفير كلمات المرور:** اعتماد خوارزمية `password_hash()` و `password_verify()`.
- **الرفع الآمن للملفات:**
  - التحقق من نوع الملف الحقيقي عبر MIME Type (`image/jpeg`, `image/png`, `image/webp`).
  - تحديد الحجم الأقصى (5MB).
  - إعادة تسمية الملفات باسم عشوائي آمن مشفر (`bin2hex(random_bytes(16))`).
  - منع تنفيذ الملفات داخل مجلدات الرفع `uploads/`.

## 🛠️ متطلبات التشغيل والتثبيت (Installation)

1. **البيئة المطلوبة:**
   - خادم محلي مثل **XAMPP** أو Wamp أو Laragon أو PHP 8.0+ و MySQL 5.7+ / MariaDB.
2. **قاعدة البيانات:**
   - السكربت التلقائي يقوم بإنشاء قاعدة البيانات `manon_db` والجداول والبيانات النموذجية بمجرد تشغيل السكربت:
     ```bash
     php install.php
     ```
   - أو يمكنك استيراد الملف اليدوي `database/database.sql` عبر phpMyAdmin.
3. **الملفات:**
   - ملف الإعدادات الرئيسي موجود في: `includes/config.php`.
